# Architecture and invariants

`src/domain/model.ts` defines normalized documents, immutable-by-convention tokens, anchors, pacing, settings, sessions and timezone helpers. A document retains normalized text with paragraph whitespace. Token offsets are **UTF-16 code-unit offsets**, matching DOM selection APIs. Tokens retain punctuation, paragraph and sentence IDs, stable numeric IDs, and boundary flags. Content/tokenizer schema versions are both 1.

`src/importers/text.ts` guards bytes before extraction; HTML is parsed into a detached `<template>` and never attached to the document. Unsafe nodes, metadata and hidden content are discarded. Only plain text is rendered by React. Markdown extraction is deliberately conservative and has an editable preview. The normalized token guard runs before saving, not after truncation. Failed imports leave no library record.

`src/reader/engine.ts` is independent of React and browser storage. Injected clock/scheduler enable deterministic tests. States are idle, paused, playing, ended. There is one scheduled callback and a generation counter; seek/dispose/pause invalidate callbacks. Playback uses monotonic deadlines. Ordinary delays of at most 16ms use the prior deadline; larger delays reset the next deadline so no burst of skipped words occurs. A callback later than max(1 second, 3 × current duration) pauses without advancing. This does not compensate for OS suspension by counting unseen words.

Base duration is 60,000 / target WPM. Punctuation factor is the maximum applicable weight: comma/colon/semicolon 1.35, sentence 1.8, paragraph 2.2. Optional lexical length >10 graphemes multiplies by 1.15. A word counts only after its interval completes, including the last word. Pause records elapsed active time, freezes the token, and retains its remaining fraction. Speed/pacing changes rescale that fraction. Seek is always paused and never counts skipped words.

`src/reader/Word.tsx` measures prefix and half-anchor widths using the actual chosen font, weight and loaded metrics; kerning/ligatures are disabled consistently for measurement and rendering. A fixed 50% origin translates the word by that measured offset, keeping the **glyph’s center** stationary. Measurements are cached with font/size/text keys, invalidated when fonts finish loading, and recomputed on resize. Long tokens shrink without wrapping, with a uniform emergency scale after the documented 16px floor.

`src/screens/Reader.tsx` connects the controller, context, selection/highlights, queued persistence and wake lock. It pauses/saves on route changes, visibility loss, pagehide, document unmount, and requested service-worker update. Persistence runs every second while playing and immediately on pause/seek/completion. Short IndexedDB transactions write only progress and the current session, not entire books. Last displayed token restores paused. Pagehide writes are best effort; periodic writes limit loss if the OS kills the process. Screen Wake Lock failures are nonfatal and visible playback state remains authoritative.

Sessions hold completed word counts, active milliseconds, settings at session start and local daily buckets. Time slices are split at actual timezone midnight by a boundary search, accounting for DST without assuming a 24-hour day. Completed words are assigned to their completion day. Historical buckets keep their recorded timezone when settings change. Rereads count as activity; no unique-coverage claim is made. Deleting a document explicitly deletes its related activity and highlights.

`src/storage/database.ts` provides Dexie database schema v2; backup/content schemas remain v1. The v2 upgrade makes hold-to-read the default for existing preferences while preserving all books and other settings. Tables: documents, progress, highlights, sessions, preferences. Books never go into localStorage. Backups are schema-versioned; full validation happens before any transaction, including regenerating tokens, checking offsets/quotes, IDs, settings, numeric counters, daily totals and document references. Restore writes atomically. Merge is idempotent by stable IDs, preserves newer positions and sessions, rejects content-ID conflicts, and restores backup settings. Replace explicitly clears/replaces all tables inside the transaction. Original imported file bytes are excluded, but normalized text/tokens permit full reading and highlight restoration.

`src/App.tsx` manages hash navigation and the library. Import, Reader, Settings, and Stats have separate screen components. Hash transitions await the reader’s save request before loading library records. Font files and all icons are local. There are no external runtime fetches for content/fonts/analytics.

`vite.config.ts` uses VitePWA/Workbox’s prompt update lifecycle, never auto-reloading a reading session. Reload awaits queued saves; save failure reports an error instead of proceeding. Shell assets, fonts and icons are precached; content remains in IndexedDB. App base, manifest identity/start/scope and SW scope agree. Different apps at separate paths have scoped workers, but IndexedDB is origin-wide: a second Stillword installation on the same origin shares the `stillword` database. A custom origin is required for fully separate libraries.

Automated tests cover clock behavior, token/anchor invariants, timezone accounting, transactional backups, browser interactions, HTML isolation, layout alignment, offline relaunch, substantial-file import, and hosting paths. Physical iPhone behavior is a separate acceptance gate.

`src/i18n/` supplies explicit English-keyed Spanish UI translations through React context. Visible UI strings and accessible labels are localized at their render sites; document fields and input values are not passed to translation. `settings.uiLanguage` is optional for compatibility with earlier backup/settings records. Numbers and day labels use the selected locale; document offsets, timing, data IDs and timezone bucket keys remain unchanged. The HTML language and page title follow the interface preference.
